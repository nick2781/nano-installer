# 卸载程序规范文档

## 卸载入口
安装阶段写入：`HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\MyApp`  
包含：DisplayName、DisplayVersion、InstallLocation、Publisher、UninstallString 等。

## 卸载流程
1. 检测并关闭正在运行的主程序与相关服务/守护进程。
2. 删除快捷方式（桌面、开始菜单、任务栏固定/快速启动）。
3. 删除安装目录及子目录（若用户勾选“保留数据”，则跳过用户数据与日志目录）。
4. 清理注册表项（卸载条目、服务、启动项、文件关联）。
5. 清理由安装器产生的临时文件与语言包残留。
6. 记录卸载日志，输出到 `%TEMP%\MyApp_uninstall.log` 或安装目录同级。
7. 结果页提示：成功/失败，并提供“打开日志”与“反馈问题”链接。

## 卸载 UI
- **确认页**：显示即将删除的内容；提供“保留用户数据”复选框。
- **进度页**：任务分步显示（关闭进程→删除快捷方式→删除文件→清理注册表…）。
- **完成页**：成功提示；失败则列出失败项摘要并可重试。

## 特殊场景
- **文件被占用**：提示用户关闭相关程序，或提供“强制关闭后继续”。
- **权限不足**：请求管理员权限重新尝试。
- **升级协同**：若为升级流程触发卸载，支持“保留当前配置与数据”。
