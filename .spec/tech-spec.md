# 安装程序技术规格文档

## 1. 项目背景
本项目旨在开发一个 **自定义安装／卸载程序**，以替代传统的 NSIS 安装脚本方案，支持以下目标：
- 与 NSIS 安装包具有同等功能（安装流程、卸载入口、组件选择、快捷方式、注册表、权限提升等）
- 支持 **多语言界面**（至少：英文、简体中文、繁体中文、日文、越南语）
- 使用现代 GUI 框架（例如 GPUI + GPUI‑Component／Rust）
- 语言包采用封装格式（参照 Electron 的 `.pak` 模式）以防止用户随意修改
- 支持打包为最终可分发的安装／卸载可执行程序（如 Windows .exe 安装器）
- 支持良好的用户体验、错误处理、日志、回滚、卸载机制

---

## 2. 架构设计
### 2.1 模块划分
- **UI 模块**
  - 向导（Wizard）容器：支持“上一步／下一步／取消”导航
  - 各安装页面组件：语言选择页、欢迎页、许可协议页、组件选择页、安装目录页、安装进度页、完成页
  - 多语言支持：资源加载、语言切换机制
  - 卸载界面组件：确认卸载页、正在卸载进度页、卸载完成页、失败提示页
  - 主题／样式（可选）
- **安装逻辑模块**
  - 用户选择数据模型（语言、组件、安装路径、快捷方式、启动选项等）
  - 安装任务执行器：根据用户选择执行“拷贝文件、注册表写入、快捷方式创建、卸载条目注册”等
  - 进度与状态反馈机制：任务状态传递给 UI，支持取消／回滚
- **卸载逻辑模块**
  - 卸载入口注册：在 Windows “应用和功能”或“控制面板”中显示卸载程序
  - 卸载任务执行器：关闭程序／服务、删除快捷方式、清理注册表、删除安装文件、删除卸载条目
  - 卸载进度反馈与错误处理：显示进度条、失败时提示、日志记录
  - 升级准备：如有升级机制，可判断旧版本卸载或替换流程
- **资源管理模块**
  - 多语言资源：翻译文本键‑值集合，封装为 `.pak` 语言包
  - 安装内容清单：定义组件 → 文件路径映射、组件依赖关系
  - 卸载清单：安装过程中记录已安装的文件／注册表项／快捷方式，以便卸载时参考
  - 配置文件：默认语言、默认路径、组件清单版本、语言包版本等
- **构建／打包模块**
  - 构建脚本：从源代码 + 资源 → 编译可执行安装器／卸载器
  - 语言包生成流程：从翻译源（如 JSON/YAML）→ 编译为 `.pak` 文件
  - Payload 打包：将应用程序文件、资源、语言包等整合进安装器资源包
  - 数字签名（如需）：在 Windows 上对安装器／卸载器签名以提升可信度
  - 输出用品：例如 `MyAppSetup_v1.0.0_en‑vi‑zh.exe` 与对应卸载程序条目
- **测试／日志模块**
  - 安装／卸载日志记录：操作步骤、成功／失败、用户选择情况、回滚情况
  - 日志存储：用户可查看、技术支持可用
  - 测试覆盖：多语言 UI、安装路径测试、权限测试、卸载流程测试

### 2.2 数据流 & 控制流
- 安装流程：启动安装器 → 语言选择 → 欢迎页 → 许可协议 → 组件选择 → 安装目录 → 安装进度 → 完成页。
- 卸载流程：用户从“控制面板／应用和功能”或安装目录运行卸载器 → 卸载确认页 → 卸载进度页 → 卸载完成页（或失败提示）。
- 安装任务模块执行期间，将状态／进度反馈给 UI；如果检测到失败，则触发回滚逻辑。
- 卸载任务执行期间，同步反馈给 UI，若失败则提示用户并记录日志。
- 构建流程：源代码 + 语言源 + 安装内容 → 语言包生成 → 打包安装器／卸载器 → 签名 → 发行。

## 3. 界面流程与页面规格
### 3.1 安装步骤流程
| 步骤编号 | 页面名称 | 功能描述 |
|-----------|----------|----------|
| 1         | 语言选择页 | 用户选择界面语言（或自动检测系统语言） |
| 2         | 欢迎页     | 展示应用名称、版本号、简短说明／Logo |
| 3         | 许可协议页 | 展示 EULA／用户协议，用户必须同意才能继续 |
| 4         | 组件选择页 | 用户选择要安装的功能／模块 |
| 5         | 安装目录页 | 用户选择或确认安装路径 |
| 6         | 安装进度页 | 显示安装任务执行状态、进度条、取消／暂停按钮（如适用） |
| 7         | 完成页     | 显示安装完成／失败信息、启动应用（可选）、查看日志链接 |

### 3.2 卸载步骤流程
| 步骤编号 | 页面名称   | 功能描述 |
|-----------|------------|----------|
| U1        | 卸载确认页 | 通知用户即将卸载，列出将删除的内容／用户可保留数据选项（如配置文件） |
| U2        | 卸载进度页 | 显示删除文件、注销服务、清理注册表、移除快捷方式等任务的进度条 |
| U3        | 卸载完成页 | 显示卸载成功信息，或若失败则显示错误提示并查看日志按钮 |

### 3.3 多语言资源与体验
- 所有 UI 文本、按钮、提示、错误信息必须支持多语言。
- 语言选择页用本地语言显示（English、中文（简体）、Tiếng Việt 等）。
- 进度页取消时提示是否回滚；失败时提供查看日志。

---

## 4. 多语言支持概要
- 支持语言：`en‑US`、`zh‑CN`、`zh‑TW`、`ja`、`vi`。
- 翻译源（JSON/YAML）在构建时转换为 `.pak` 二进制语言包并内置或随安装器分发。
- 运行时加载 `.pak` 并提供回退到默认语言（如 `en‑US`）。

---

## 5. 安装/卸载逻辑要点
- 安装：校验路径→提权→拷贝文件→写注册表/卸载条目→创建快捷方式→记录日志→失败回滚。
- 卸载：关闭进程/服务→删除快捷方式→清理文件→清理注册表→记录日志→结果页面。

---

## 6. 构建与打包
- 生成语言 `.pak`；仅包含支持的语言以控制体积。
- 可选签名安装器和卸载器；提供 SHA256 校验。

---

## 7. 测试
- 单测：语言包加载、键查找、回退；拷贝/注册表/快捷方式/回滚；卸载各步骤。
- 集成：全流程安装与卸载、权限场景、多语言布局。
- 兼容：Win10/11、不同系统语言、路径含空格/非 ASCII、组件组合。

---
