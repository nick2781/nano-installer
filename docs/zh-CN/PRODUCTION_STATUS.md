# 当前生产状态

**当前实现尚不能用于生产发布。** 安装动作会写入文件和注册表，请只在一次性虚拟机中验证。

## 已验证

- 构建器与运行时是两个独立程序，安装包不含构建器。
- ZIP 与 7z payload 按文件头识别并选择对应运行时。
- 两个运行时都能正确解开真实归档，结果与预期 SHA-256 一致。
- 卸载程序使用自己的运行时和页面列表，不链接任何解包后端。
- CLI 与 Windows 10+ GUI 驱动同一套构建 API，GUI 依赖不会进入运行时。
- 安装包携带 payload、项目资源，以及带独立图标与版本信息的自包含卸载程序。
- 安装会解压 payload、把文件与卸载程序部署到新目录、写入 manifest 与卸载项；卸载只删除
  manifest 中记录的内容。
- 目标目录已有同一项目时按原地升级处理，删除新版 payload 不再包含的文件，任一步失败则恢复到
  先前版本。
- 首屏原生渲染背景位图与 Unicode 文字，窗口无边框圆角，可拖动、最小化和关闭。
- 每个产物的 Windows 7 SP1 x64 兼容性都经过 PE 导入审计。
- 进度页实时汇报状态，完成页可启动已部署的应用。
- 快捷方式与自启动项在安装时创建、卸载时还原，回滚路径同样覆盖。
- 卸载会终止运行中的产品、清理快捷方式，并且只在用户取消勾选保留数据时删除声明的用户数据。
- `scripts/install.rhai` 与 `scripts/uninstall.rhai` 由内嵌 Rhai 引擎执行，原语复用内置的部署、
  回滚与 manifest 代码；脚本失败会回滚，脚本漏做清单清理时由库回退处理。
- 流式布局覆盖嵌套 `VBox`、`HBox`、`Content`，支持内边距、外边距、百分比尺寸、
  `justify-content` 与 `align-items`。

## 已知限制

- 安装包不会自动申请提权。写入 `Program Files` 需要以管理员身份启动。
- 运行中的卸载程序要到下次重启时才删除自身文件。
- 运行时内嵌 Rhai 引擎，每个运行时体积从约 0.57-0.66 MB 增至约 1.8-1.9 MB。
- 链接点击、目录选择框与 Select 键盘操作尚未实现。

完成签名与 Windows 7 验收后，产品即可按 `examples/TapTap` 的结构接入。
