# 当前生产状态

**当前实现尚不能用于生产发布。** 安装动作会写入文件和注册表，请只在一次性虚拟机中验证。

## 已验证

- 构建器与运行时是两个独立程序，安装包不含构建器。
- ZIP 与 7z payload 按文件头识别并选择对应运行时。
- 两个运行时都能正确解开真实归档，结果与预期 SHA-256 一致。
- 卸载程序使用自己的运行时和页面列表，不链接任何解包后端。
- CLI 与 Windows 10+ GUI 驱动同一套构建 API，GUI 依赖不会进入运行时。
- 安装包携带 payload、项目资源，以及带独立图标与版本信息的自包含卸载程序。
- 安装会解压 payload、把文件与卸载程序部署到新目录、写入 manifest 与卸载项；卸载只删除
  manifest 中记录的内容。
- 目标目录已有同一项目时按原地升级处理，删除新版 payload 不再包含的文件，任一步失败则恢复到
  先前版本。
- 首屏原生渲染背景位图与 Unicode 文字，窗口无边框圆角，可拖动、最小化和关闭，可点击控件上
  显示手型光标。
- 每个产物的 Windows 7 SP1 x64 兼容性都经过 PE 导入审计。
- 进度页实时汇报状态，完成页可启动已部署的应用。
- 快捷方式与自启动项在安装时创建、卸载时还原，回滚路径同样覆盖。
- 卸载会终止运行中的产品、清理快捷方式，并且只在用户取消勾选保留数据时删除声明的用户数据。
- `scripts/install.rhai` 与 `scripts/uninstall.rhai` 由内嵌 Rhai 引擎执行，原语复用内置的部署、
  回滚与 manifest 代码；脚本失败会回滚，脚本漏做清单清理时由库回退处理。
- 流式布局覆盖嵌套 `VBox`、`HBox`、`Content`，支持内边距、外边距、百分比尺寸、
  `justify-content` 与 `align-items`。
- 文案中的 Markdown 链接可以点击打开配置好的网址，`close_confirm` 会先弹本地化确认问题，
  目录选择框会把选中的路径写回布局中的 TextInput。
- 控件会绘制布局声明的 `background`、`border-color` 与 `border-radius`；语言菜单展开时
  上下键、回车与 Esc 可用。
- 文本框可以直接编辑：点击落下闪烁光标，输入即插入，Backspace 与 Delete 删除字符，方向键、
  Home、End 移动光标；按住左键拖动或双击选中文字并高亮显示，Ctrl+A 全选，Ctrl+C/X/V 复制、
  剪切与粘贴，Ctrl+Z/Y 撤销与重做，Ctrl+Backspace/Delete 与 Ctrl+左右键按词操作，连续输入合并
  为一步。声明 `readonly` 的字段保持只读展示。
- 流式布局按 `flex-basis` 作为起点分配剩余空间，逐个元素支持 `align-self`，嵌套容器会按自身
  内容参与外层测量，绝对定位元素可以用 `right`/`bottom` 或 `inset` 简写从另一侧定位。
- 容器声明 `flex-wrap` 后一行放不下会折行；默认仍然先压缩可收缩项。
- 安装包会写入应用程序清单：打开 `install.require_admin` 后由 Windows 在进程启动前弹出提权确认，
  `ui.dpi_aware` 告诉系统窗口是否自行缩放。两者都不配置时保持普通程序的运行方式。
- 构建时会拿每个语言文件与默认语言、以及页面实际引用的键做比对，报出缺文案的语言，以及
  `supported_locales` 里列了却没有对应文件的语言。
- 卸载完成后，临时目录中的清理副本会立即删除卸载程序与已清空的安装目录。目录里还有用户自己
  的文件时保留目录，清理副本自身也会退出并消失。

## 阻塞发布的问题

1. 没有代码签名。Authenticode（含双签名）尚未接入，也没有证书。
2. 尚未在真实 Windows 7 SP1 机器上完成验收。

## 已知限制

- 运行时内嵌 Rhai 引擎，每个运行时体积从约 0.57-0.66 MB 增至约 1.8-1.9 MB。
- 提权后的安装包与卸载程序都以高完整性运行，只写 `%LOCALAPPDATA%` 的产品应关闭
  `install.require_admin`。
- 清单申请的是旧版 `dpiAware`。尚未申请逐显示器感知，把安装窗口拖到缩放比例不同的显示器上由
  Windows 负责缩放。

完成签名与 Windows 7 验收后，产品即可按 `examples/TapTap` 的结构接入。
