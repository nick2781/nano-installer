## 使用说明

### 当前可以做的
1. **构建语言包**
   ```bash
   cargo run --bin langpack-builder -- locales dist/locales
   ```

2. **测试静默安装逻辑**（需要先准备 payload）
   ```bash
   cargo build --release --bin installer
   ./target/release/installer /S /D=C:\TestInstall
   ```

- 实际的应用程序 payload 文件

## 技术亮点 ⭐

1. **模块化设计**：清晰的模块划分，易于维护和扩展
2. **类型安全**：Rust 的类型系统保证内存安全
3. **异步支持**：使用 tokio 异步运行时
4. **二进制语言包**：防止用户篡改，带校验
5. **详细日志**：便于调试和用户反馈
6. **灵活的任务系统**：易于添加新的安装步骤
