## ⏳ 下一步工作

### 第 1 优先级：实现 UI 页面

使用 gpui-component 实现三个主要页面：

#### 1. 配置页（Config Page）
```
需要的组件：
- Button（主按钮、链接按钮、浏览按钮）
- Checkbox（同意协议、创建快捷方式、自动启动）
- Input（安装路径输入框，只读）
- Label（文字标签）
- Layout（布局容器）
```

**关键功能**：
- 展开/收起更多选项
- 同意协议才能安装
- 路径浏览
- 磁盘空间显示

#### 2. 安装进度页（Installing Page）
```
需要的组件：
- ProgressBar（进度条）
- Label（状态文字）
```

**关键功能**：
- 实时进度更新
- 状态文字更新
- 背景图片显示

#### 3. 完成页（Finish Page）
```
需要的组件：
- Button（立即使用）
- Label（完成提示）
- Image（Logo）
```

**关键功能**：
- 启动应用按钮
- 关闭安装器
