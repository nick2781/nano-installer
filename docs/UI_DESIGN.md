## GPUI 实现要点

### ⚠️ 重要提示

GPUI 是 Zed 编辑器的 UI 框架，主要特点：
1. **基于 GPU 渲染**：需要现代 GPU 支持
2. **响应式布局**：类似 SwiftUI/React
3. **数据驱动**：状态管理
4. **还在开发中**：API 可能变化

### Windows 7 兼容性考虑

由于目标是 Windows 7 SP1+，需要注意：
- GPUI 需要 DirectX 11+ 或 Vulkan
- Windows 7 需要安装 Platform Update
- 某些旧硬件可能不支持

### 替代方案建议

如果 GPUI 在 Windows 7 上有问题，可考虑：

1. **egui** - 更成熟的纯 Rust GUI
2. **iced** - 类似 Elm 架构
3. **slint** - 声明式 UI，更接近传统 GUI
4. **native-windows-gui** - 原生 Windows 控件

这些框架对老系统支持更好。
