# Code of conduct

## What this is

Nano Installer is a Windows installer framework that people are invited to use, test, and change.
This file says what behaviour is expected in its issues, pull requests, commit messages, reviews, and
anywhere else someone is speaking for the project. It is short on purpose: it is meant to be read and
applied, not cited.

## What is expected

- **Argue about the code, not the person.** "This reads the registry without checking the view" is a
  review; "you clearly do not know Win32" is not.
- **Explain the reasoning.** Say what breaks, on which Windows version, and how you saw it. A report
  that names the log, the version, and the step is worth more than one that names a feeling.
- **Assume the other person is trying.** This project has a maintainer in one time zone answering
  when they can, and contributors who may be reading English or Chinese as a second language. Neither
  is a reason to be sharp.
- **Write in English or Chinese.** Both are welcome; nobody is asked to write in a language they are
  guessing at.
- **Stay on topic.** Reports, patches, questions, and disagreements about the product belong here.
  Unrelated campaigns — political, promotional, or personal — do not.
- **No harassment.** No slurs, no sexual attention, no deliberate intimidation, no following someone
  from thread to thread, no publishing private information. This is the one part with no room for
  interpretation.

## Scope

This applies to everything in this repository and to anything a person says while acting as a
maintainer or as a representative of the project elsewhere.

## What happens

The maintainer may edit or delete a comment, close a thread, decline a contribution, or block an
account, with or without explanation, in proportion to what happened. A first step is usually a
request to stop; sustained or severe behaviour skips that step.

## Reporting

If behaviour breaks this file, tell the maintainer — on the issue or in a direct message on GitHub
when the matter is not sensitive, or through GitHub's
[report abuse](https://github.com/contact/report-abuse) form when it is. Conduct reports are read by
the maintainer; a report about the maintainer goes to GitHub, since there is nobody else here to read
it.

## Attribution

The standards above follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1, cut down to what this project can actually enforce.
