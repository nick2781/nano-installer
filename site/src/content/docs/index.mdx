Nano Installer turns a product project into a single setup `.exe`. You define the product,
pages and installation behavior; the builder bundles your application with a native Win32 runtime.
Users can install, upgrade and uninstall without downloading an installer framework.

Build a project from the command line:

```powershell
.\nano-installer-native-x64.exe build --project C:\path\to\my-project
```

<Aside type="note" title="Windows requirements">
The CLI and generated installers support **Windows 7 SP1 x64 and later**. The GUI requires
Windows 10 or later. All published executables use the same x64 build target; see
[Windows compatibility](/reference/windows-compatibility/) for the runtime requirements.
</Aside>

## What you get

| Capability | Use it for | Read next |
| --- | --- | --- |
| ZIP and 7z payloads | Ship application files in one self-contained setup | [Configuration](/reference/configuration/) |
| Branded native pages | Define images, controls, actions and DPI scaling in XML | [Page layout](/guides/page-layout/) |
| Localization | Ship translated UI text in UTF-8 JSON files | [Languages](/guides/languages/) |
| Upgrade and rollback | Replace an installed version and recover after a failed step | [Production status](/project/status/) |
| Delta packages | Ship changed files against a verified installed base | [Command line](/reference/cli/) |
| Uninstall and user data | Remove recorded files and preserve user data by default | [Configuration](/reference/configuration/) |
| Scripts and plugins | Add Rhai steps and DLLs through the versioned C ABI | [Custom steps](/guides/custom-steps/), [Plugin ABI](/guides/plugins/) |
| Silent installation and MSI | Integrate with CI and managed deployment | [Distribution](/guides/distribution/) |

## Technical notes

The [production status](/project/status/) records verified behavior and remaining gaps.
Windows 7 installation, upgrade and uninstall have been exercised in a VM, but the framework's
tests do not replace acceptance of your own payload, scripts and plugins. Repository releases
are unsigned; your product pipeline can sign the setup, embedded uninstaller and MSI through
the `finalize` hooks. See [distribution](/guides/distribution/) for the checklist.

Read [architecture](/project/architecture/) for the bundle and runtime boundaries,
[test coverage](/project/coverage/) for the evidence behind each behavior, and
[build and release](/reference/build-and-release/) to contribute to the framework.
