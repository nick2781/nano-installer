Start with the [quick start](/quick-start/) or [visual builder](/guides/visual-builder/), then choose
the task your product needs. Configuration is enough for the built-in deployment flow; scripts
and plugins extend it when you need additional steps.

## Customize the installer

| Task | Guide |
| --- | --- |
| Define pages, images, controls and keyboard behavior | [Page layout](/guides/page-layout/) |
| Add translated UI text and verify locale files | [Languages](/guides/languages/) |
| Add installation steps and page hooks | [Custom steps](/guides/custom-steps/) |
| Call a project-owned native DLL | [Plugin ABI](/guides/plugins/) |
| Port instructions from an existing NSIS project | [Migrating from NSIS](/guides/migrating-from-nsis/) |
