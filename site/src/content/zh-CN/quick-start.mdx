本教程为 `MyApp.exe` 创建按用户安装的安装包。你需要一台 Windows x64 机器，以及准备分发的
应用文件。下载的构建器不需要 Rust 工具链；首次构建成功后，再将产品名称和可执行文件换成自己的。

<Steps>

1. ## 下载工具

   从同一个[发布版本](https://github.com/nick2781/nano-installer/releases/latest)下载以下文件，
   放在同一个目录：

   | 文件 | 用途 |
   | --- | --- |
   | `nano-installer-native-x64.exe` | 命令行构建器 |
   | `lzma-stub-native.exe` | 7z 应用归档运行时 |
   | `zlib-stub-native.exe` | ZIP 应用归档运行时 |
   | `uninst-stub-native.exe` | 内嵌卸载运行时 |
   | `SHA256SUMS.txt` | 预期的 SHA-256 摘要 |

   运行 `certutil -hashfile nano-installer-native-x64.exe SHA256`，将结果与 `SHA256SUMS.txt`
   对应行比较，并逐个校验运行时。

   <Aside type="note" title="使用同一版本的工具">
   构建器与三个运行时必须来自同一个发布版本。可视化构建器是可选工具，要求 Windows 10 及以上。
   仓库发布的产物未签名，详见[发布你的产品](/zh-CN/guides/distribution/)。
   </Aside>

1. ## 准备项目

   创建以下目录，包括空的 `assets` 目录。将 `MyApp.exe` 及其依赖放到 `app/` 下。

   ```text
   my-project/
     installer_config.json
     app/
       MyApp.exe
     assets/
     layouts/
       install.xml
       uninstall.xml
     locales/
       zh-CN.json
     payload/
       app.zip
   ```

   在 `my-project/` 中生成应用归档：

   ```powershell
   Compress-Archive -Path .\app\* -DestinationPath .\payload\app.zip -Force
   ```

   <Aside type="caution" title="检查归档根目录">
   `MyApp.exe` 必须位于归档根目录，不要再套一层 `app` 文件夹。`install.exe_name` 需要与归档中的
   路径一致，否则安装后无法启动应用。
   </Aside>

   将下列文件保存为 UTF-8。项目使用内置部署步骤，不需要 Rhai 脚本或插件；其他设置见
   [配置参考](/zh-CN/reference/configuration/)。

   ### 产品配置

   ```json title="installer_config.json"
   {
     "project": { "name": "MyApp", "version": "1.0.0", "publisher": "Example Company" },
     "output": { "installer_name": "MyApp_Setup.exe" },
     "resources": { "payload_file": "payload/app.zip" },
     "localization": { "default_locale": "zh-CN", "supported_locales": ["zh-CN"] },
     "install": {
       "default_path": "%LOCALAPPDATA%\\MyApp",
       "exe_name": "MyApp.exe",
       "require_admin": false
     },
     "registry": { "uninstall_key": "HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Uninstall\\MyApp" },
     "wizard": {
       "pages": [{ "id": "install", "layout": "layouts/install.xml" }],
       "uninstall_pages": [{ "id": "uninstall", "layout": "layouts/uninstall.xml" }]
     },
     "advanced": { "silent_mode_support": true, "uninstall_mode_support": true }
   }
   ```

   ### 页面

   ```xml title="layouts/install.xml"
   <Page width="480" height="240" background="#FFFFFFFF">
     <Label text="MyApp" left="32" top="28" width="416" height="32" font-size="22" color="#FF202020" />
     <Button text="@install" action="install" left="32" top="120" width="200" height="40" color="#FF202020" />
     <Button text="@close" action="close" left="248" top="120" width="200" height="40" color="#FF202020" />
   </Page>
   ```

   ```xml title="layouts/uninstall.xml"
   <Page width="480" height="240" background="#FFFFFFFF">
     <Label text="MyApp" left="32" top="28" width="416" height="32" font-size="22" color="#FF202020" />
     <Button text="@uninstall" action="uninstall" left="32" top="120" width="200" height="40" color="#FF202020" />
     <Button text="@close" action="close" left="248" top="120" width="200" height="40" color="#FF202020" />
   </Page>
   ```

   ### 界面文案

   ```json title="locales/zh-CN.json"
   { "install": "安装", "uninstall": "卸载", "close": "关闭" }
   ```

   单页项目通过消息框报告完成结果。完整向导通常再增加独立的进度页和完成页，见
   [页面布局](/zh-CN/guides/page-layout/)。

1. ## 构建安装包

   在下载的工具所在目录运行：

   ```powershell
   .\nano-installer-native-x64.exe build --project C:\path\to\my-project
   ```

   生成文件是 `my-project/dist/MyApp_Setup.exe`。构建器按归档文件头选择 ZIP 运行时，并嵌入卸载
   程序。运行时位于其他位置时，加上 `--stubs C:\path\to\stubs`；全部参数见
   [命令行参考](/zh-CN/reference/cli/)。

1. ## 验证安装与卸载

   先将安装包复制到干净的虚拟机中。上述配置安装到当前用户的 `%LOCALAPPDATA%` 下，不请求提权。

   1. 运行安装包并选择**安装**，确认目标目录中出现 `MyApp.exe` 和 `uninst.exe`。
   2. 启动 `MyApp.exe`，确认应用依赖齐全。
   3. 在 Windows「程序和功能」中找到 MyApp，执行卸载，确认清单记录的应用文件被移除。
   4. 重新安装，再用变更后的应用归档构建 `1.0.1`，覆盖安装到 `1.0.0` 上，验证升级。
   5. 按[发布你的产品](/zh-CN/guides/distribution/)中的命令验证静默安装和卸载。

   正式产品项目还需要加入图标、产品元数据和品牌界面，并完成
   [发布验收清单](/zh-CN/guides/distribution/)。错误处理和日志位置见[故障排查](/zh-CN/guides/troubleshooting/)。

</Steps>

## 使用 TapTap 示例

`examples/TapTap` 演示了完整的品牌向导。

<Aside type="note" title="准备示例资源">
请通过 Git LFS 克隆；源码 ZIP 中的图片和压缩工具是
指针文件。仓库不包含 `examples/TapTap/payload/app.7z`，构建前需要自行补齐。
示例品牌资源不受 MIT 许可覆盖，不能用于自己的产品。
</Aside>
