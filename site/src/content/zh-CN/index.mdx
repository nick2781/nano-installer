你交付的只有一个 exe，用户双击就能装上你的产品。把配置、素材和应用文件放进一个目录，Nano Installer
就把它打成一份 Windows 安装包：图标、页面和文案都由你定，而用户的机器不用预装任何东西。

## 它给你什么

| | |
| --- | --- |
| 只需交付一个文件 | 一个安装包 exe，内置你的图标、版本信息和品牌素材 |
| 干净的机器就能装 | 不用先装运行环境，也不依赖框架：要用的东西都在安装包里 |
| 页面归你 | 用 XML 写页面布局，配上自己的背景图和按钮图 |
| 内置 11 种界面语言 | 内置 11 种，再加一种语言就是一个 JSON 文件 |
| 进度与完成页 | 进度页说明当前在做什么，完成页则能直接启动刚装好的应用 |
| 升级、回滚与更新包 | 重跑一次就是原地升级，某一步失败会回滚；`--delta-from` 只发改变了的文件 |
| 卸载 | 只回收自己写下的东西，用户数据默认保留 |
| 管理员权限 | 只在配置要求时才向 Windows 申请 |
| 脚本与插件 | 用 Rhai 写安装和卸载步骤；插件是照 [`include/nano_plugin.h`](/zh-CN/guides/plugins/) 编的 DLL |
| 读屏可用 | 页面、焦点、输入的字符和实时进度都会播报，既走 MSAA，也走 `IDispatch` |
| 界面或命令行 | Windows 10 及以上的可视化构建器，或者让 CI 驱动同一套引擎 |
| 还能出 MSI | `--msi` 把安装包封成 MSI，供企业用 Windows Installer 分发 |

## 上手

从[最新发布](https://github.com/nick2781/nano-installer/releases/latest)取构建器和那三个运行时，因为
构建器会在自己旁边找它们。然后让它对着项目目录构建：

```powershell
.\nano-installer-native-x64.exe build --project C:\path\to\my-project
```

接着照[快速开始](/zh-CN/quick-start/)生成第一个安装包，再在虚拟机里试一遍；也可以改用
[可视化构建](/zh-CN/guides/visual-builder/)，让它驱动同一套引擎。

从源码构建工具是贡献者的事，见[构建与发布](/zh-CN/reference/build-and-release/)。
