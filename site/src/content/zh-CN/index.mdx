Nano Installer 将产品项目构建成一个安装包 `.exe`。你定义产品信息、界面和安装行为，构建器将
应用文件与原生 Win32 运行时一起打包。用户可以安装、升级和卸载，无需另外下载安装框架。

通过命令行构建项目：

```powershell
.\nano-installer-native-x64.exe build --project C:\path\to\my-project
```

<Aside type="note" title="Windows 运行要求">
命令行构建器和生成的安装包支持 **Windows 7 SP1 x64 及以上**，可视化构建器要求 Windows 10
及以上。所有发布的可执行文件采用同一套 x64 构建目标；运行条件见
[Windows 兼容性](/zh-CN/reference/windows-compatibility/)。
</Aside>

## 功能

| 能力 | 用途 | 从这里开始 |
| --- | --- | --- |
| ZIP 与 7z 应用归档 | 将应用文件打包为一个自包含的安装程序 | [配置参考](/zh-CN/reference/configuration/) |
| 原生品牌界面 | 用 XML 定义图片、控件、动作和 DPI 缩放 | [页面布局](/zh-CN/guides/page-layout/) |
| 多语言 | 用 UTF-8 JSON 文件提供界面译文 | [多语言](/zh-CN/guides/languages/) |
| 升级与回滚 | 替换已安装版本，并在步骤失败时恢复 | [当前生产状态](/zh-CN/project/status/) |
| 增量更新包 | 校验已安装的基线后，仅部署发生变化的文件 | [命令行参考](/zh-CN/reference/cli/) |
| 卸载与用户数据 | 删除清单记录的文件，默认保留用户数据 | [配置参考](/zh-CN/reference/configuration/) |
| 脚本与插件 | 用 Rhai 添加步骤，通过版本化的 C ABI 调用 DLL | [自定义步骤](/zh-CN/guides/custom-steps/)、[插件 ABI](/zh-CN/guides/plugins/) |
| 静默安装与 MSI | 接入 CI 和集中部署 | [发布你的产品](/zh-CN/guides/distribution/) |

## 指南

1. [生成第一个安装包](/zh-CN/quick-start/)，在干净的虚拟机里验证安装与卸载。
2. [定制界面](/zh-CN/guides/page-layout/)，再[添加语言](/zh-CN/guides/languages/)。
3. 配置无法覆盖产品需求时，[添加安装步骤](/zh-CN/guides/custom-steps/)。
4. 分发前，[签名并验收产品安装包](/zh-CN/guides/distribution/)。

迁移已有产品时，参考[从 NSIS 迁移](/zh-CN/guides/migrating-from-nsis/)，逐项对应配置、布局和
脚本 API。构建或部署失败时，先查[故障排查](/zh-CN/guides/troubleshooting/)。

## 技术说明

[当前生产状态](/zh-CN/project/status/)记录已验证的行为和剩余空白。Windows 7 上的安装、升级
和卸载已经在虚拟机中运行过，但框架测试不能替代你对应用文件、脚本和插件的验收。仓库发布的
产物没有代码签名；产品流水线可以通过 `finalize` 钩子签名安装包、内嵌卸载程序和 MSI。
验收清单见[发布你的产品](/zh-CN/guides/distribution/)。

[架构](/zh-CN/project/architecture/)说明捆绑格式和运行时边界，
[测试覆盖](/zh-CN/project/coverage/)列出各项行为的验证证据，
[构建与发布](/zh-CN/reference/build-and-release/)介绍如何参与框架开发。
