先完成[快速开始](/zh-CN/quick-start/)或使用[可视化构建器](/zh-CN/guides/visual-builder/)，再按
产品需要选择任务。内置部署流程可以通过配置完成，需要额外步骤时再接入脚本和插件。

## 定制安装包

| 任务 | 指南 |
| --- | --- |
| 定义页面、图片、控件和键盘行为 | [页面布局](/zh-CN/guides/page-layout/) |
| 添加界面译文并校验语言文件 | [多语言](/zh-CN/guides/languages/) |
| 添加安装步骤和页面钩子 | [自定义步骤](/zh-CN/guides/custom-steps/) |
| 调用项目自己的原生 DLL | [插件 ABI](/zh-CN/guides/plugins/) |
| 迁移已有 NSIS 项目的指令 | [从 NSIS 迁移](/zh-CN/guides/migrating-from-nsis/) |
